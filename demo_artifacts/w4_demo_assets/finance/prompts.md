# 财务 Demo 可复制文案

## 报告输入框问题

```text
请基于华信咨询待审资料包，生成一份年度财务分析与审阅报告，并指出营业成本、资产负债配平、现金跨期、存货占比和应收增长是否存在异常。
```

## A/B 双轨讲解词

A 轨讲法：

```text
A 轨是不加规则约束的裸模型路径。它会直接读待审资料里的数值，所以很容易把第 3 期营业成本 3,000、异常资产总计、异常存货和应收数据原样写进报告，形成看似流畅但带错数的结论。
```

B 轨讲法：

```text
B 轨先跑规则核查，再由 Projector 对硬勾稽错误做数值修正，最后用受控槽位生成报告。这里重点看营业成本从 3,000 修正为 2,000，资产负债配平和现金跨期问题会被标出，行业画像和比率背离作为风险提示进入审阅口径。
```

## 报告生成口径

```text
报告不是只总结上传表格，而是按“规则命中 -> 数值修正 -> 风险提示 -> 审阅结论”的顺序生成。硬性恒等式错误以修正值为准，行业画像和同比背离以审阅风险表达，不直接改写全部业务事实。
```
