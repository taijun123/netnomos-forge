# W4 财务 Demo 资产包

本目录用于 W4 叙事演示的 finance demo。演示时从这里选择上传文件，报告问题和讲解词也放在同一目录，避免临场查找。

## 目录内容

| 文件 | 用途 |
|---|---|
| `huaxin_audit_package.csv` | 演示上传文件，华信咨询 8 期待审资料包，故意包含财务数值异常。 |
| `truth_table.json` | 错误注入真值表，供讲解和复核使用。 |
| `huaxin_clean_reference.csv` | 清洁参考资料，只作对照，不在演示中上传。 |
| `finance_training_clean_960_correct.csv` | 完整 960 行仿真正确训练数据，英文列名，用于讲解规则学习来源。 |
| `finance_training_clean_960_correct_zh.csv` | 完整 960 行仿真正确训练数据，中文列名参考。 |
| `prompts.md` | 可直接复制的中文问题、A/B 双轨讲解词和报告生成口径。 |
| `references/` | 从场景源码复制的相关说明、报告模板、manual rules 和 golden 规则参考。 |

## 演示流程

1. 打开 `http://127.0.0.1:5173/#/finance`。
2. 在“训练资料预览”查看合成训练集样例，点击“开始规则学习”。
3. 进入“资料上传”，选择并上传本目录的 `huaxin_audit_package.csv`。
4. 确认页面显示文件名与 `dataSourceId`，进入“规则核查”。
5. 点击“运行资料规则核查”，等待事件流完成。
6. 到“输入报告问题”步骤，复制 `prompts.md` 里的“报告输入框问题”。
7. 进入 “A/B 双轨”，点击“运行实时 A/B 双轨”，查看 A 轨标红报告、B 轨合规报告和干预日志。
8. 到“报告预览/下载”查看 Markdown 报告。

## 报告输入框问题

```text
请基于华信咨询待审资料包，生成一份年度财务分析与审阅报告，并指出营业成本、资产负债配平、现金跨期、存货占比和应收增长是否存在异常。
```

## 预期命中

- `R01` 进销存勾稽：第 3 期 COGS 写成 3,000，按期初存货 10,000 + 采购 4,000 - 期末存货 12,000 应为 2,000。
- `R02` 资产负债配平：第 5 期资产总计比负债加权益多 500。
- `R04` 现金跨期：第 1 期期末现金 8,000，第 2 期期初现金写为 8,500。
- `R06` 行业画像：咨询公司第 8 期期末存货占资产 35%，偏离咨询业低存货常态。
- `R07` 比率背离：第 7 期应收账款同比 +300%，收入只增长约 15%。

## 当前 W4 限制

- 上传文件会被后端保存到 `demo_artifacts/uploads/finance_v1/` 并登记 `dataSourceId`。
- 当前 W4 管线仍复用稳定财务演示结果：后端会构造华信咨询待审资料包并运行固定核查/双轨流程，尚未解析任意上传 CSV 的每一行作为真实输入。
- 因此演示口径应说“上传用于触发和登记资料来源，核查展示复用 W4 稳定管线结果”，不要说系统已经支持任意财务文件自动解析。
